# ПРИЛОЖЕНИЕ 4. Диаграмма последовательности

```mermaid
sequenceDiagram

    actor User as Покупатель
    participant App as Мобильное приложение
    participant API as API Gateway
    participant Cart as Сервис корзины
    participant Order as Сервис заказов
    participant Payment as Сервис оплаты
    participant PayGW as Платёжный сервис
    participant Account as Учётная система
    participant Push as Сервис уведомлений

    User->>App: Переходит к оформлению заказа

    App->>API: Запрос данных корзины
    API->>Cart: Получение корзины
    Cart-->>API: Состав и стоимость корзины
    API-->>App: Данные корзины

    User->>App: Выбирает способ получения
    User->>App: Выбирает способ оплаты
    User->>App: Подтверждает заказ

    App->>API: POST /orders
    API->>Order: Создание заказа
    Order->>Cart: Проверка состава корзины
    Cart-->>Order: Подтверждение состава

    Order->>Order: Расчёт итоговой стоимости
    Order-->>API: Создан заказ и сумма
    API-->>App: Номер заказа и сумма

    App->>Payment: Инициирование оплаты
    Payment->>PayGW: Запрос проведения платежа
    PayGW-->>Payment: Результат платежа

    alt Оплата успешна
        Payment-->>App: Успешная оплата
        App->>API: Подтверждение оплаты
        API->>Order: Обновление статуса заказа
        Order->>Account: Передача заказа
        Account-->>Order: Подтверждение приёма
        Order-->>API: Статус «Принят»
        API->>Push: Формирование уведомления
        Push-->>App: Уведомление о статусе заказа
        App-->>User: Отображение подтверждения заказа

    else Оплата отклонена
        Payment-->>App: Отказ в оплате
        App-->>User: Сообщение об ошибке оплаты
    end
