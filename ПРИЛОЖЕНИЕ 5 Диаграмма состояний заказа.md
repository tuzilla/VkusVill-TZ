# ПРИЛОЖЕНИЕ 5. Диаграмма состояний заказа

```mermaid
stateDiagram-v2

    [*] --> Создан

    Создан --> ОжидаетОплаты : заказ сформирован

    ОжидаетОплаты --> Оплачен : успешная оплата
    ОжидаетОплаты --> Отменён : отказ или ошибка оплаты
    ОжидаетОплаты --> Отменён : отмена пользователем

    Оплачен --> Принят : подтверждение учётной системой

    Принят --> Собирается : заказ передан на сборку

    Собирается --> ГотовКПолучению : самовывоз
    Собирается --> ПереданВДоставку : доставка

    ГотовКПолучению --> Получен : заказ выдан пользователю

    ПереданВДоставку --> Доставлен : заказ доставлен

    Получен --> Завершён
    Доставлен --> Завершён

    Отменён --> [*]
    Завершён --> [*]
    ```
