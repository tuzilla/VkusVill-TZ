## 4.3. Требования к серверной части

В качестве технологической основы серверной части принимаются Kotlin, Spring Boot, REST API, формат обмена данными JSON, СУБД PostgreSQL 16, Redis, Apache Kafka и Docker. Указанные решения могут быть уточнены на этапе проектирования при сохранении требований к системе, установленных настоящим техническим заданием.
